# Smart Expense Tracker Dashboard

## Project Overview
The Smart Expense Tracker is an Excel-based dashboard designed to organize personal expenses and analyze spending patterns. It provides a summary of expenses and interactive filters to help users explore their spending.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Slicers
- Data visualization

## Key Features
- Total expense, transaction count, and average expense metrics
- Category-wise expense summary
- Expense visualization using charts
- Interactive filters for category, payment mode, and month
- Organized expense records for analysis

## Skills Demonstrated
- Data organization and summarization
- Excel formulas and PivotTables
- Dashboard design
- Data visualization
- Interactive reporting

## Project File
Download `Expense_Dashboard.xlsx` from this repository and open it in Microsoft Excel to explore the dashboard and its interactive filters.
